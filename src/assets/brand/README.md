# ACS brand assets

Place the official logo files here when available:

- `acs-logo-full-color.svg` or `.png`: full ACS logo for white/light backgrounds.
- `acs-logo-white.svg` or `.png`: full ACS logo for dark/orange backgrounds.
- `acs-symbol-white.svg` or `.png`: ACS symbol for decorative low-opacity use.

The current app includes a clearly marked text fallback only because no attached logo files were present in the workspace. Replace the paths in `src/data/content.ts` after adding the official assets.
